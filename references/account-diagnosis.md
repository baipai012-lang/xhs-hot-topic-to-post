# 小红书账号 API 数据诊断框架

基于小红书创作服务平台 `creator.xiaohongshu.com` 的 6 个核心 API，对账号进行结构化诊断。

## 安全边界

- 不索要 Cookie、a1、Token、Authorization
- 不绕过风控、签名、反爬
- 只分析用户手动采集的 Response JSON
- 风控接口只识别，不逆向

---

## 6 个核心 API

| # | API | 用途 |
|:--:|------|------|
| 1 | `/api/galaxy/creator/data/note_detail_new` | 7/30天观看、点赞、涨粉、每日趋势 |
| 2 | `/api/galaxy/creator/datacenter/note/analyze/list?type=0&page_size=10&page_num=1` | 每篇笔记曝光/阅读/点击率/互动/涨粉 |
| 3 | `/api/galaxy/creator/data/fans/overall_new` | 粉丝总数、涨粉/掉粉趋势 |
| 4 | `/api/galaxy/creator/data/active_fans_new` | 活跃粉丝列表、互动次数 |
| 5 | `/api/galaxy/v2/creator/datacenter/audience/view/periods` | 观看时段分布 |
| 6 | `/api/galaxy/v2/creator/datacenter/audience/source/account` | 流量来源（搜索/推荐/主页） |

## 衍生指标计算

| 指标 | 公式 | 基准线 |
|------|------|------|
| 阅读转化率 | read_count / imp_count | — |
| 封面点击率 | coverClickRate | <5%弱 / 5-8%一般 / 8-12%好 / >12%优秀 |
| 互动量 | like + fav + comment + share | — |
| 互动率 | 互动量 / read_count | <1%弱 / 1-3%普通 / 3-5%好 / >5%强 |
| 观看转粉率 | 涨粉 / 观看数 | — |
| 主页访客转粉率 | 涨粉 / 主页访客 | — |
| 近期爆发 | 7天观看 / 30天观看 | >80%说明最近起量 |

## 账号阶段判断

```
冷启动期 → 冷启动破局期 → 增长验证期 → 稳定增长期 → 成熟运营期
```

判断依据：粉丝数、7天观看占比、是否有单篇跑出、内容方向是否稳定、涨粉是否连续。

---

## 单篇笔记诊断标签

| 标签 | 含义 |
|------|------|
| 高曝光高点击高停留 | 优质样本，值得复制 |
| 高曝光高点击低停留 | 标题封面强，内容承接弱 |
| 高曝光低点击高停留 | 内容好但外层包装弱 |
| 低曝光高停留 | 选题小众但内容有价值 |
| 高涨粉 | 人设/信任感样本 |
| 低曝光低点击低停留 | 无效内容，不建议继续 |

---

## 流量结构诊断

| 来源占比 | 账号类型 | 优化重点 |
|------|------|------|
| 搜索 > 50% | 搜索型 | 关键词、标题具体度、选题时效性 |
| 首页推荐 > 40% | 推荐型 | 封面、情绪、争议、互动率 |
| 个人主页 > 10% | 主页承接强 | 关注引导、系列内容 |

---

## 观看时段判断

| 时段 | 内容消费场景 |
|------|------|
| 上午高 | 学习、资讯、工作前浏览 |
| 中午高 | 碎片化休息 |
| 下午高 | 工作间隙、赛前查询 |
| 晚上高 | 娱乐、体育、消费决策 |
| 深夜高 | 情绪、娱乐、陪伴型 |

## 输出模板（14项）

```
1. 一句话诊断
2. 账号当前阶段
3. 核心数据概览
4. 流量结构诊断
5. 内容方向诊断
6. 单篇笔记表现诊断
7. 粉丝增长诊断
8. 活跃粉丝诊断
9. 互动与转粉诊断
10. 观看时段诊断
11. 当前账号优势
12. 当前账号问题
13. 账号定位判断
14. 最终结论
```

### 一句话诊断模板

```
你的账号目前处于【阶段】，已经跑出【内容方向】信号，
但主要问题是【问题1】、【问题2】、【问题3】。
```

### 注意事项

- 粉丝 < 30 时，只判断增长趋势，不判断人群结构
- 粉丝 < 100 时，不做强画像判断
- 不要因为某篇阅读最高就直接判定最值得复制，要同时看点击率、停留、互动、涨粉
- 搜索流量高时，重点分析关键词和标题；首页推荐低时，重点看互动率和内容方向一致性
